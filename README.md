# Домашнее задание — Ansible и PostgreSQL

В этом ДЗ я написал Ansible-роль для установки и настройки PostgreSQL на Ubuntu 24.04.

Роль устанавливает PostgreSQL, настраивает каталоги и конфигурацию, создаёт пользователей и базы данных. Также устанавливается postgres-exporter, чтобы можно было получать метрики работы базы.

Для проверки использовал PostgreSQL 16 и postgres-exporter 0.20.1.

## Структура проекта

- `postgres.play.yml` — основной плейбук, который запускает роль.
- `roles/postgres/` — сама роль со всеми задачами, шаблонами и хендлерами.
- `inventories/main/` — инвентарь и настройки для vm1.
- `ansible.cfg` — настройки Ansible.
- `requirements.yml` — необходимые коллекции.
- `logs/` — логи запусков и результаты проверок.

В моём случае vm1 — это тот же сервер, с которого запускается Ansible. Подключение идёт по SSH через 127.0.0.1 от пользователя ans-user.

## Как запустить

Сначала нужно установить коллекции:

    ansible-galaxy collection install -r requirements.yml

Затем проверить подключение к машине:

    ansible vm1 -m ping

После этого можно запускать плейбук:

    ansible-playbook postgres.play.yml

Для работы с зашифрованными переменными нужен файл vault-pass. Он не добавляется в Git, поэтому при запуске на другой машине необходимо настроить свой Vault и заново зашифровать пароль пользователя.

## Что получилось

PostgreSQL устанавливается из стандартных репозиториев Ubuntu. Данные хранятся в /data/postgres/data.

Для примера я создал базу app_db и пользователя app_user. Его пароль хранится в зашифрованном виде через Ansible Vault.

Для мониторинга используется отдельный пользователь postgres_exporter с правами pg_monitor. Сам экспортер работает как systemd-служба и отдаёт метрики на порту 9187.

## Проверка

Проверить, что PostgreSQL работает:

    sudo -u postgres psql -c 'SELECT 1'

Посмотреть базы данных:

    sudo -u postgres psql -c '\l'

Посмотреть пользователей:

    sudo -u postgres psql -c '\du'

Проверить экспортер:

    curl -s http://127.0.0.1:9187/metrics | grep '^pg_up '

Если всё нормально, последняя команда выводит pg_up 1.

## Идемпотентность

Одно из главных требований задания — повторный запуск не должен ничего менять.

Я запустил полный плейбук повторно и получил changed=0, failed=0. PostgreSQL и экспортер при этом продолжили нормально работать.

## Логи

Результаты работы лежат в папке logs:

- `01-full-playbook-run.txt` — первый успешный запуск полной версии плейбука.
- `02-idempotency-run.txt` — повторный запуск с changed=0.
- `03-checks.md` — проверки служб, баз, пользователей и метрик.

PostgreSQL изначально настраивался поэтапно, поэтому первый успешный запуск полной версии плейбука выполнялся уже на частично настроенной машине.
